COMO CONECTAR CON TABLEPLUS
  Ninguna BD tiene IP publica: los servicios son internos del cluster (ClusterIP). Hay que abrir un tunel con
  kubectl port-forward en una terminal y dejarla abierta; luego en TablePlus: Host 127.0.0.1 + puerto local.

  - cqrs_read (AWS):
      aws eks update-kubeconfig --region us-west-2 --name comedor
      kubectl -n comedor port-forward svc/postgres-cqrs 5435:5432          -> TablePlus: PostgreSQL 127.0.0.1:5435
  - menu_inventario (AWS):
      kubectl -n comedor port-forward svc/mongo 27017:27017                -> TablePlus: MongoDB 127.0.0.1:27017, base menu_inventario, Auth DB = admin
  - comensales_reservas (Azure):
      kubectl --kubeconfig comedor-infra/respaldo/kube-aks.yaml -n comedor port-forward svc/postgres-comensales 5433:5432
                                                                           -> TablePlus: PostgreSQL 127.0.0.1:5433
  - pagos_tickets (GCP):
      gcloud container clusters get-credentials comedor-gke --zone us-central1-a --project <TU_PROYECTO_GCP>
      kubectl -n comedor port-forward svc/postgres-pagos 5434:5432         -> TablePlus: PostgreSQL 127.0.0.1:5434
  - Usuario/clave de cada Postgres y de Mongo: kubectl -n comedor get secrets  (y ver el que usa cada manifiesto).
  - agentes.db: kubectl -n comedor get pods  (el que empieza con ia-ml-service)  y luego
      kubectl -n comedor cp <pod-ia-ml-service>:/data/agentes.db ./agentes.db   -> abrir ese archivo en TablePlus (SQLite)
  - DynamoDB (real, sin tunel): consola de AWS > DynamoDB > Tablas (region us-west-2) o 'aws dynamodb scan --table-name sagas'.

NOTAS DE LECTURA
  - Los nombres de columna de comensales_reservas van en camelCase (TypeORM): en TablePlus/SQL hay que
    ponerlos entre comillas dobles, por ejemplo "estudianteId".
  - Las claves foraneas entre servicios NO existen en la BD: reserva.estudianteId, pagos.reserva_id, etc.
    son referencias logicas (cada servicio tiene su BD). Solo se listan las FK reales que declara el dump.
  - Marcadas con [SOLO EN CODIGO] estan las tablas que el codigo crea pero que no aparecen en el respaldo.
